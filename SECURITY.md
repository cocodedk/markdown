# Security policy

## Reporting a vulnerability

Please report security problems privately by email to **babak@cocode.dk**, not in a public issue.
Include what you found, how to reproduce it, and the app version.

You will get a reply within a week. Fixes ship in the next release, and you are credited unless
you ask not to be.

## Supported versions

Only the latest release is supported.

## Scope

The app asks for no permissions, uses no network and runs no scripts from a document. Anything that
breaks one of those promises is in scope.
