Privacy policy: Markdown

This policy covers the Android app Markdown (package dk.cocode.markdown) from Cocode.

Effective 7 October 2026.

Summary

Markdown collects no personal data and sends nothing anywhere. It asks Android for no permissions, so it cannot use the network at all. It reads a file only when you open it or send it to the app, and it writes a file only when you tap Save. There is no account, no analytics, no advertising and no crash reporting.

What is collected

Nothing is collected. The app handles two things, and only on your phone:

  • The text of the file you open or share, or the text you type in the editor. The app keeps it in memory to show it and to edit it. A file over 2 MB is not opened.
  • The file's name, which Android gives the app, shown as the title at the top of the screen.

The app has no account, no identifier of you or your phone, no location, no contacts and no usage statistics. If you write to Cocode (see Contact), Cocode receives your message and your email address. That has nothing to do with the app.

Servers the app contacts

None. The app has no network permission (see Permissions) and its code makes no network requests. The web view that draws your document has network loads switched off, so a picture in a document is never fetched: it shows as [image: description].

A link in a document is only an address until you tap it. When you do, the app hands the address (a web or an email address) to Android, which opens it in the browser or the mail app you use. That app contacts the link's server, not Markdown.

This website is separate from the app. When you read this page, your browser fetches a stylesheet and a script for the Cocode page frame from brand.cocode.dk, and the page itself comes from GitHub Pages. Those are requests from your browser, not from the app.

Permissions

The app asks for no Android permissions: no internet, no storage, no camera, no microphone, no location, no contacts and no notifications.

It still reads and saves files, because you hand each file to it. When you tap Open, Android's own file picker lets you choose a file, and Android gives the app access to that one file. The same happens when another app opens a file in Markdown or shares text or a file to it. Saving uses the same access: the app writes to the file Android gave it, or to the place you choose in Android's picker.

The app lists the kinds of file it can open (Markdown and plain text) so Android offers it in "Open with". That is not a permission.

What stays on the phone

The app stores nothing of its own: no database, no settings file, no cache and no history. While it runs, the text of the open file and the file's address are held in memory. Changes you have not saved exist only there. Done drops them, and they are gone when the app is closed.

The only thing the app writes is the file itself, and only when you tap Save, to the file you opened or to the place you chose. That file is yours and stays where you put it. Delete it with your file manager.

The app also switches off Android's app backup, so none of it is copied into an Android backup.

Third parties

The app sends data to no third party. It has no analytics, advertising or crash-reporting library. The libraries inside it are Android's Jetpack and Compose (Google), Kotlin and its coroutines (JetBrains), and the open-source CommonMark and autolink libraries that turn Markdown into a page. They run inside the app, and because the app has no network permission, none of them can connect anywhere.

Other parts of Android and other apps take part when you use Markdown, under their own policies:

  • Android System WebView draws the page. In this app its scripts, file access and network loads are switched off.
  • The file picker, and the app that holds your file or sends it to Markdown: a file manager, a mail app or a cloud storage app. A cloud storage app may download a file when you open it and upload it again after you save. That is that app, not Markdown.
  • The browser or the mail app that opens a link you tap.
  • Your keyboard, when you type in the editor. Markdown has no keyboard of its own.

Your rights

Because the app collects no personal data and Cocode receives none from it, there is nothing to access, correct or delete. Under the General Data Protection Regulation (GDPR) you have the right to ask what personal data is held about you, to have it corrected or deleted, and to complain. Write to bb@cocode.dk if you are in doubt. You can also complain to the Danish Data Protection Agency, Datatilsynet.

Contact

Cocode (Babak Bandpey), bb@cocode.dk. You can also open an issue on GitHub. Issues there are public.

Changes

If this policy changes, the date at the top changes and this section says what is new. Earlier versions are in the project's history on GitHub.
