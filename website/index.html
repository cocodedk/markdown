Markdown

Someone sends you a README.md. Tap it, pick “Markdown”, and read it the way it was written to look. Fix a line, format it, save it.

Get the app Android 8.0 or newer. Free, Apache-2.0.

Open a file or shared text

  • Tap a .md file in a file manager, email app or chat app, and choose “Markdown” if it is offered.
  • Share a file or a piece of text from an app that shares Markdown or plain text.
  • Or start the app and pick a file with its Open button, or start a new one with New.

What it does

MarkdownShows headings, tables, strikethrough and task lists, and turns web addresses into clickable links.
Light and darkFollows your phone's theme.
Any directionPersian, Arabic and Hebrew paragraphs read right to left, English left to right, in the same file.
ZoomPinch to enlarge small text.
EditTap Edit to change the text, with buttons for bold, italic, headings, lists, quotes, code and links, then Save. Files the other app lets you change are saved in place; for anything else you choose where the copy goes.

What it will not do

It asks for no permissions and cannot connect to the internet, so remote images stay unloaded. A link you tap opens in your web browser, not in Markdown. Nothing in a document runs as a script. No accounts.
