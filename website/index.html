Markdown Viewer

Someone sends you a README.md. Tap it, pick Markdown Viewer, and read it the way it was written to look.

Download the APK Android 8.0 or newer. Free, Apache-2.0.

Open it from anywhere

  • Tap a .md file in a file manager, a mail or a chat, and choose Markdown Viewer.
  • Share a file or a piece of text to it from any app.
  • Or start the app and pick a file with its Open button.

What it shows

MarkdownCommonMark with GitHub's extensions: tables, strikethrough, autolinks and task lists.
Light and darkFollows your phone's theme.
Any directionPersian, Arabic and Hebrew paragraphs read right to left, English left to right, in the same file.
ZoomPinch to enlarge small text.

What it will not do

It asks for no permissions and never goes online, so remote images stay unloaded. Nothing in a document runs as a script. It only views: no editing, no accounts.
