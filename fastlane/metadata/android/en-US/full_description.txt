Markdown lets you read, edit and save Markdown files on Android. Markdown is a way of writing formatted text with plain characters: for example, a # at the start of a line makes a heading.

Tap a .md file in a file manager, email app or chat app and choose “Markdown” if it is offered. Or start Markdown and tap Open to choose a file.

<b>Features</b>
<ul>
<li>Choose a Markdown file with Open, or receive Markdown or plain text from compatible apps</li>
<li>Shows tables, strikethrough and task lists, and turns web addresses into clickable links</li>
<li>Follows your phone's light or dark theme</li>
<li>Edit the text and save it back, or start a new file</li>
</ul>

<b>Private by design</b>
<ul>
<li>No permissions</li>
<li>No network: pictures from the web are not loaded</li>
<li>Documents cannot run scripts (small programs)</li>
</ul>

No accounts.
